# The One-Line Exit

One original funny resignation letter, exactly one line, at most 140 characters.

Entry: `Dear boss, I am resigning to pursue my dream of never attending another meeting that could have been an email. My last day was yesterday.`

Run: `python3 main.py` (writes the line to `/output/entry.txt`).
